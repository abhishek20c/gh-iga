What gh-iga Flags

Thresholds are configurable with documented CLI flags.

Human access risk

  • Admin sprawl across many repositories
  • Inactive users retaining write or admin access
  • Privileged outside collaborators
  • Repositories with too many admins
  • Orphaned users and direct-access drift

Non-human identity and integration risk

  • Overprivileged or org-wide GitHub Apps
  • Suspended apps still installed
  • Read-write or stale deploy keys
  • Unrotated Actions secrets
  • Insecure webhooks and write-default workflow tokens
